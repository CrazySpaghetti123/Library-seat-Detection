## Context

南台科大圖書館需要精確追蹤與管理座位，專案目前剛剛開始，我們決定打下良好的基礎：同時引入 `SeatStatus` 的結構並實作座位的「預訂基礎邏輯 (Booking Logic)」。

## Goals / Non-Goals

**Goals:**
- 提供統一的 `SeatStatus` 資料型別或 Enum，包含四個主要狀態。
- 實作一個「預訂功能」的核心模組，驗證狀態轉換與防護機制。

**Non-Goals:**
- 連接真實的資料庫（暫時以記憶體/模擬資料代替）
- 撰寫完整的前端網頁操作介面
- 完整的手機號碼驗證等登入細節

## Decisions

### Decision 1: 使用純邏輯分離實作
由於專案還沒有固定的大型框架，我們將在 `src` 目錄下建立獨立的 `models` (資料結構) 與 `services` (業務層) 檔案，把核心功能寫好。未來不管用什麼框架去接 API 都能輕易把這段程式碼掛載上去。
